Vanilla Server Updated to 26.3

The vanilla server has been updated to minecraft version 26.3, meaning we now have access to Sulfur Cubes, Caves, and Geysers from 26.2 and the new Dappled Forest biome from 26.3

There have been some backend/technical changes to how the server is being hosted. The most significant change is that the server has been moved from Exaroton to a private hosting solution generously provided by Ghosti. This move has allowed us to dedicate significantly more resrouces to the server, going from 4gb to 64gb of RAM; as a result the render distance has been significantly increased. This also means the server is now open 24/7 and does not close when no players are online, meaning chunk loading should be more stable and there should be less friciton when trying to join.
